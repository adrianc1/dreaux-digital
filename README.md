# Dreaux Digital

Personal freelance portfolio site for Dreaux Digital — a solo web development studio specializing in modern, responsive front-end and full stack solutions.

## Stack

- **React** — component-based UI
- **Tailwind CSS** — utility-first styling
- **Vite** — build tool and dev server
- **EmailJS** — contact form without a backend
- **React Router** — client-side routing

## Sections

- **Hero** — intro and CTA
- **About** — who I am and what I do
- **Services** — custom dev, support, and analytics
- **Projects** — selected work (TraceRoot, Sports PWA, TruckFix)
- **Process** — how I work with clients
- **Blog** — write-ups and updates
- **Contact** — EmailJS-powered contact form
